# Leakage-free MLP supplementary figure captions

**Supplementary Fig. S4 | MLP hyperparameter and training-size ablations.** Panels (a–e) report the validation MAPE obtained by varying one hyperparameter at a time around the common public baseline: batch size 32, learning rate 0.01, hidden dimension 256, network depth 4, dropout 0.1, and weight decay $10^{-5}$. Orange markers denote the value selected from each validation-only sweep. Panel (f) uses the frozen jointly selected configuration (batch size 256, learning rate $5\times10^{-4}$, hidden dimension 256, network depth 3, dropout 0, and weight decay $10^{-5}$) with strictly nested training subsets of 8,000, 16,000, ..., 80,000 samples. One `random_state=42` permutation of the fixed 80,000-sample training fold defines all prefix subsets, so each smaller training set is contained in every larger one. All sizes share the same fixed 20,000-sample validation fold for checkpoint selection and early stopping; their frozen checkpoints are evaluated on the same independent 2,000-sample seed42 development-evaluation set. Points and error bars show the mean and sample standard deviation over five training seeds (202601–202605). The independent seed43 final test set is not used for this ablation.

**Supplementary Fig. S5 | Training histories of the five final MLP models.** The left and right panels show, respectively, the training and validation mean-squared error in the log-transformed target space for the five training seeds. All runs used the jointly selected configuration and the same fixed 80,000/20,000 development split. Checkpoint selection used validation performance only.

**Supplementary Fig. S6 | Validation-based descriptor ablations for the MLP.** Panels show models trained (a) using only one selected descriptor group, (b) after leaving out one selected descriptor group, (c) after leaving out one of the 11 selected descriptors, and (d) after leaving out one of the original 35 descriptors without redundancy removal. Each horizontal box shows the median and interquartile range across five training seeds; whiskers extend to 1.5 times the interquartile range, and overlaid points show all five individual runs. In panels (a–c), the vertical dashed line denotes the five-seed mean of the complete 11-descriptor model; in panel (d), it denotes the five-seed mean of the complete unreduced 35-descriptor model. All models used the frozen jointly selected MLP configuration and the fixed 80,000/20,000 split; the final test set was not used.
