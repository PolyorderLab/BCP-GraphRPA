# k* transfer main-evidence source data

This directory contains the numerical source data used by
`notebooks/kstar_transfer.ipynb` to generate the main-text transfer figure.

- `kstar_transfer_label_curve_five_seed_mape.csv` contains test MAPE for five
  paired seeds at 100, 250, 500, 1,000, and 2,000 target-labelled training
  architectures.
- `kstar_transfer_full_data_five_seed_mape.csv` contains the corresponding
  five-seed comparison using 80,000 target-labelled training architectures.
- `kstar_transfer_summary.csv` is regenerated by the notebook from the two
  seed-level tables.

For the limited-label experiment, training subsets were drawn from the fixed
80,000-architecture training pool. Within each seed they were strictly nested,
paired across methods, and balanced over two-, three-, four-, and five-block
architectures. Sizes divisible by four used equal group counts. At size 250,
the two remainder samples were rotated across block-count groups between seeds.
Checkpoint selection used a separate 1,000-architecture validation subset with
250 samples per block count. Every run was evaluated on the same independent,
block-count-balanced seed-43 test set of 2,000 architectures.

The numerical tables were copied without modification from the corrected
experiment archive `sourcecode/kstar_transfer_main_evidence_20260913/figures/`.
